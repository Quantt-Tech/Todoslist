# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Report them privately to the project maintainers through the designated security contact.

Please include:
- Clear description of the vulnerability
- Steps to reproduce
- Potential impact
- Relevant safe-to-share evidence
- Suggested mitigation, if known

## Do Not Include

Never publish passwords, API keys, access tokens, credentials, or other sensitive information in an issue or pull request.

## Scope

Reports may involve:
- Authentication or authorization
- Data exposure
- Injection vulnerabilities
- Unsafe client-side behavior
- Dependency vulnerabilities
- Notification/reminder security
- Privacy issues

We appreciate responsible disclosure.
